# Mathel：問題の作り方（作成者向け）

対象は数学・物理学科の学部1年〜院試受験者、および数学検定1級・統計検定（2級・準1級・1級）の受験者。
答えを覚えるのではなく「自力で方針を立てて解ける」力をつけるアプリの演習問題。
教科書の演習問題・院試問題・検定の出題傾向の「核」を抜き出して新しく作る（数値・設定・問い方を変える。原文の丸写しはしない）。

## 1問の形（JSON 配列の1要素）

```json
{
  "tid": "AN-03",
  "subject": "解析",
  "field": "複素解析",
  "level": 2,
  "theme": "留数定理による実積分",
  "minutes": 15,
  "q": "問題文（LaTeX）",
  "answer": "答え（LaTeX、小問ごとに (1) … (2) … と並べる）",
  "solution": "解答・解説（LaTeX）",
  "idea": "核となるアイデア（1〜2文）",
  "tags": "タグ1,タグ2",
  "input": "入力用の答え（下の書式）"
}
```

- `subject` / `field` は tools/math_fields.py の名前と完全に一致させる
- `level`（大学数学）：0=基礎（意欲的な高校生でも解ける）, 1=標準（教科書の例題）, 2=演習（章末問題）, 3=院試, 4=院試難関
- `level`（検定）：1=易しめ, 2=本番標準, 3=本番の難問。検定問題は 0 と 4 を使わない
- `minutes`：想定時間（分）。3〜40
- 文体は「である」調。句読点は「，」「．」（全角）。数式は `$...$`、別行立ては `\[...\]`
- 小問は `\begin{enumerate} \item … \item … \end{enumerate}`。番号は自動で (1)(2)… になる
- 使える文章命令：enumerate, itemize, tabular, \textbf, \emph, \quad, \\。それ以外の文章用 LaTeX 命令・図は使わない（図は言葉で説明する）
- 数式中は KaTeX で描ける命令だけ。\bm は不可→\boldsymbol。\mathbb, \mathcal, \mathfrak, \operatorname, \pmatrix 環境（\begin{pmatrix}）, \begin{cases}, \begin{aligned} は可
- 解説では最終的な答えを `\boldsymbol{...}` で太字に。段落は空行で区切る

## 入力用の答え（`input`）

アプリはこの列で自動採点する。**計算で答えが決まる小問は必ず自動採点できる形にする**（証明・説明だけの小問は `記述`）。
数学の問題は証明が多くなりがちなので、1問の中に「値を求める小問」を最低1つ入れることを目安にする（院試難関の純粋な証明問題は例外でよい）。

- 小問があるときは1行に1小問、行頭に `(1)` `(2)` … 小問の数と行数を一致させる。小問がない問題は番号なしの1行
- 1つの小問に答えが複数あるときは ` ; ` で区切る
- `ラベル：値`（全角コロン）でラベルを付けられる：`位数：12 ; 中心の位数：2`
- 文字式：`sqrt(2)/2`、`x^2 e^(-x)`、`n(n+1)/2`、`pi/4`、`a^n/(1-a)`
  - 変数は「1文字（＋添字）」だけ：`x`, `a_1`, `λ` / `lambda`, `θ` / `theta`
  - `ab` は a×b の意味。2文字以上の名前の変数は作れない
  - 使える関数：sin cos tan exp log(=ln) ln sqrt abs sinh cosh tanh arcsin arccos arctan、定数 pi, e
  - 階乗・二項係数・ゼータ値などは数値か式で書く（`120`、`pi^2/6`）。`n!` は使わない
  - 問題文で与えた記号だけを使う。答えに出てくる文字はすべて問題文に出てくること
- 整数・有理数・根号などの厳密な値は `≈` を付けない：`3/2`, `sqrt(3)/2`, `2pi`
- 統計の数値計算（有効数字つき）は先頭に `≈`：`≈2.01`、`≈0.0228`（相対誤差2%まで正解）。許容幅を変えるなら `≈0.05 (5%)`
  - 正規分布表・t 分布表・χ² 分布表などの値は**問題文で与える**（例：「$z_{0.025}=1.96$ を用いてよい」）
- 指数表記は `6.6e-4`
- 順不同の組 `{1, -1, 2}`、順序のある組 `(a, b)`、比 `1:2:3`、範囲 `0<x<1`、場合分け `場合分け{ a<1 → … | a>=1 → … }`
- 選択式（統計検定2級など）：問題文に ①〜⑤ を並べ，「番号で答えよ」とし，input は番号の数字だけ：`3`
- 証明・説明は `記述`（自己採点）。**`記述：要点` の形で必ず要点（証明の骨子を1〜2文）を書く**
- 「はい/いいえ」で答える判定は、数で問い直す（例：「可換なら 1，そうでなければ 0 と答えよ」）か、`記述：…` にする
- 行列・ベクトルそのものは入力できない。成分・トレース・行列式・固有値の集合・次元・階数などスカラーで問う

## 品質

- 数学として正しいこと。**答えは必ず自分で検算する**（python3 と sympy が使える。数値・積分・固有値などは計算して確かめる）
- 「答え」列の LaTeX と「入力用の答え」は同じ値にする（検査で SymPy 照合される）
- 1問に小問を2〜4個つけ、誘導で山を登る形を基本にする（前の小問の結果を使う）
- 同じパターンの問題を重ねない。各分野で概念確認・計算・証明がバランスよく入るように
- 解説は、方針（なぜその道具を使うか）→ 計算・論証 → 結論 の順で。省略しすぎない

## 検査

```sh
python3 tools/validate_new.py new/<ファイル>.json <作業用フォルダ>
```

「すべて OK」になるまで直す。SymPy 照合の「（照合できない）」は、答えの LaTeX と入力用の答えが本当に一致しているなら、
書き方を SymPy が読める形（`\frac{a}{b}`、`\sqrt{…}`）に寄せて解消する。

## 基礎レベル（level 0）の作り方

「意欲的な高校生」が、その問題文だけを頼りに解けることが条件。

- 前提知識は高校数学（数III・数Cまで）
- 大学の概念（群、位相、ε-δ、ルベーグ測度、多様体…）は、**問題文の中で定義を与えて**から使う
- 小問は2〜3個。(1) で定義を具体例に当てはめる → (2) で意味のある結果を出す、の流れ
- 想定時間 5〜12 分。答えはなるべく自動採点（数・簡単な式）
- 解説は高校生が読んでわかる言葉で。最後に「この分野では次に何を学ぶか」を1文添える
