# Mathel（大学数学・数学検定1級・統計検定）

Mathel は、答えを見せるのではなく、自力で方針を立てて解ける頭をつくる大学数学の演習アプリ（試作版 v0.2）。
[Lemma 受験数学](https://github.com/mythos0217/lemma-math)・[ぶつりば](https://github.com/mythos0217/butsuriba) と同じエンジン・同じ形式で、
数学科・物理学科の学部〜院試の範囲と、数学検定1級・統計検定（2級・準1級・1級）の演習を扱います。
iPhone・iPad のブラウザで動き、ホーム画面に追加するとアプリとして使えます（PWA）。

## コースと収録分野

「今日」画面の上のタブでコースを切り替えます。ランダム出題・分野ごとの演習・復習は、選んだコースの中で行います。

| コース | 分野 |
|---|---|
| 大学数学・解析 | 微分積分学／多変数解析／実解析／複素解析／常微分方程式／関数解析／偏微分方程式 |
| 大学数学・代数 | 線形代数／群論／環論／体論／ガロア理論／表現論 |
| 大学数学・幾何 | 集合と位相／線形幾何／位相幾何／微分幾何／リーマン幾何／微分トポロジー |
| 大学数学・その他 | 確率論・統計学／離散数学／数理論理／応用数学 |
| 数学検定1級 | 解析／線形代数／代数・整数論／確率・統計／幾何・複素関数（テーマに【1次】【2次】） |
| 統計検定2級 | データの記述と要約／確率と確率分布／標本分布／推定／仮説検定／回帰分析と相関／標本調査と実験計画 |
| 統計検定準1級 | 確率と確率分布／推定と検定／回帰分析と線形モデル／多変量解析／時系列解析／ベイズ統計と計算統計 |
| 統計検定1級 | 確率分布と極限定理／点推定と十分統計量／区間推定と仮説検定／線形モデルと多変量解析／統計応用 |

科目と分野の一覧は `tools/math_fields.py`（アプリ側は `js/catalog.js` の `SUBJECT_ORDER`・`COURSES`）。

収録数は 805 問：大学数学は各分野 20 問（23 分野・460 問），検定は各分野 15 問（数検1級 75・統計2級 105・準1級 90・1級 75）。

### 網羅表

`tools/COVERAGE.md` に，分野ごとの単元（標準的な教科書・院試・各検定の出題範囲から計約 1000 単元）と，
それを扱う問題 ID の対応をまとめています。`[ ]` の単元は未カバー（約 9%）で，次に問題を足すときの候補です。

難易度は、大学数学が 0=基礎（意欲的な高校生でも解ける）・1=標準・2=演習・3=院試・4=院試難関 の5段階、
検定コースが 1=易・2=標準・3=難 の3段階。

## ぶつりばからの違い

- **アイコン**：深い紫に、細身の積分記号と黄金らせん（オリジナル）
- **マスコット**：亀の「ゼノ」（ゼノンの「アキレスと亀」から）。名言はカントール・ヒルベルト・ポアンカレ・ガウス・ハーディ・岡潔・小平邦彦など数学者のことば
- **コース切り替え**：大学数学／数検1級／統計検定2級・準1級・1級。記録はコースをまたいで共通
- **計算トレーニング**：行列と固有値・留数計算・確率統計の計算・特殊な積分・ベクトル解析・近似と展開・微分・積分
- **グラフの例**：正規分布、テイラー近似、一様収束しない関数列、フーリエ級数、カージオイド、リサジュー、楕円曲線、ニュートン法など。3D はトーラス、メビウスの帯、極値と鞍点など
- 学習記録は `mathel.v1` という別の名前で保存するので、受験数学版・ぶつりばと同じ端末で使っても混ざらない

そのほか（段階ヒント、自信度、自己採点、復習の間隔調整、グラフ電卓、ライト／ダーク、オフライン動作、記録の書き出し）はぶつりばと同じです。

## 問題管理表から問題を取り込む

問題は `Mathel問題管理表.xlsx`（問題一覧シート）で管理します。シートの形式はぶつりばと同じです。

```sh
pip3 install openpyxl sympy antlr4-python3-runtime==4.11
python3 tools/import_xlsx.py Mathel問題管理表.xlsx
node tools/check_answers.mjs data
node tools/check_katex.cjs
```

### 新しい問題を作るとき

書き方の基準は `tools/PROBLEM_GUIDE.md`。JSON で作って検査し、問題管理表にまとめます。

```sh
python3 tools/validate_new.py new/AN-1.json   # 書式・KaTeX・入力用の答え・SymPy 照合・重複
python3 tools/make_xlsx.py                    # new/*.json → Mathel問題管理表.xlsx
```

## GitHub Pages で公開する

1. GitHub で新しいリポジトリを作る（例：`mathel`、Public）
2. このフォルダの中身を**そのまま**リポジトリの直下にアップロード
3. 「Settings」→「Pages」→ Branch を `main` / `/ (root)` にして Save
4. 1〜2分後に `https://<ユーザー名>.github.io/mathel/` で開ける

更新したときは `sw.js` の `VERSION` を上げると、端末のキャッシュも入れ替わります。
